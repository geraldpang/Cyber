3. Asset Exposure

Describe the asset's exposure characteristics. These answers are used to calculate the suggested inherent likelihood for applicable threats.
⚙ Exposure-to-Likelihood Configurator

Configure the default inherent likelihood for each threat and how strongly each asset exposure factor changes that likelihood. The suggested likelihood is calculated as: Base Likelihood + applicable Exposure Adjustments, capped between 1 and 5.

Adjustment scale: 0 = no effect · 0.25 = small · 0.5 = moderate · 0.75 = strong · 1.0 = very strong
